0解压，并放到正确位置

  1. 从 GitHub 仓库选择 Code → Download ZIP
  2. 双击解压（或右键 → 解压 / 解压缩）。
  3. 将解压后的文件夹命名为：wechat-channels-ai-assistant
  4. 务必把整个文件夹复制到「桌面」再使用。

为什么必须放到桌面？
如果文件还在微信/QQ/网盘的下载缓存目录里，系统常会拦截或报 Permission denied。桌面上最稳。

怎么复制到桌面：

  1. 点选整个「wechat-channels-ai-assistant」文件夹
  2. 右键 → 复制
  3. 打开桌面（空白处）
  4. 右键 → 粘贴

后面所有操作，都只用桌面上这一份。

Mac 苹果电脑详细步骤

重要提醒（Mac）

  • 不要普通双击黑色的 .command 文件（会被系统拦住）。
  • 不要在微信文件夹里直接运行。
  • 不要依赖自动安装 Homebrew（国内网络经常失败）。请先手动安装 Node。
  • 第一次会稍慢（要装项目依赖），请保持网络畅通，黑窗口不要关。

先装 Node（只需一次）

  1. 用 Safari 打开 https://nodejs.org
  2. 点绿色按钮 macOS 安装程序(.pkg)
  3. 一路继续安装完成
  4. 关掉所有旧终端窗口，重新开一个新终端（很重要）
  5. 在新终端输入下面两行，确认有版本号：
    node -v npm -v

若提示 command not found：重启一次电脑后再开新终端检查。

1打开说明文件夹

  1. 打开桌面上的 wechat-channels-ai-assistant
  2. 再打开里面的 苹果电脑请看这里
  3. 你会看到：
    • 打开办法.html（就是本说明，可双击）
    • 看这里.txt
    • 请右键点我启动.command（真正的启动脚本）

2打开「终端」

  1. 键盘同时按：Command ⌘ + 空格键
  2. 出现搜索框后，输入：终端（或 Terminal）
  3. 按回车
  4. 出现黑底（或白底）窗口，这就是终端

3先输入 bash 和空格

在终端里用键盘输入下面 4 个字符（最后是空格）：

bash

注意：

  • 是英文 bash，不是中文
  • bash 后面必须有一个空格
  • 输入完先不要按回车，光标停在空格后面

4把启动文件拖进终端

  1. 回到访达，打开：桌面 → wechat-channels-ai-assistant → 苹果电脑请看这里
  2. 找到 请右键点我启动.command
  3. 用鼠标按住它，拖到终端窗口里松开
  4. 终端里会出现一长串路径，这是正常的
  5. 按回车

正确示例（路径因人而异，但前面必须有 bash）：

bash /Users/你的用户名/Desktop/wechat-channels-ai-assistant/苹果电脑请看这里/请右键点我启动.command

5等待安装与启动

终端可能依次出现：

  • 检测 Node / npm / FFmpeg
  • 正在安装项目文件 / npm 相关文字
  • 很多 npm warn 黄色警告 → 可以忽略，不是失败
  • 最后会启动网页服务

请一直看着这个窗口，不要关闭。首次可能要几分钟。

浏览器一般会自动打开；如果没有，自己打开浏览器访问：

http://localhost:3000

没有 FFmpeg 也可以先用脚本工作台；发布前审片以后再装 FFmpeg。

6（推荐）生成下次一键图标

第一次成功跑起来后，脚本会尝试在桌面创建 视频号助手.command。

若桌面上没有，可在终端再开一个新窗口，整段粘贴下面内容后回车：

ROOT="$HOME/Desktop/wechat-channels-ai-assistant" && cat > ~/Desktop/视频号助手.command <<EOF #!/bin/bash cd "$ROOT" || exit 1 [ -x /opt/homebrew/bin/brew ] && eval "\$(/opt/homebrew/bin/brew shellenv)" echo "正在启动…请不要关闭本窗口" (sleep 5; open "http://localhost:3000") & npm run dev EOF chmod +x ~/Desktop/视频号助手.command && echo "已创建：桌面上的「视频号助手」"

以后多数情况：直接双击桌面 视频号助手 即可。

Windows 详细步骤

1放到桌面

同样把整个「wechat-channels-ai-assistant」文件夹复制到桌面。

2双击一键启动

  1. 打开桌面上的文件夹
  2. 双击 一键启动.bat
  3. 若弹出「未知发布者 / Windows 已保护你的电脑」：
    • 点「更多信息」
    • 再点「仍要运行」
  4. 若弹出权限窗口，选「是」

3等待黑窗口

  • 首次会自动安装 Node、FFmpeg、项目依赖，需要联网
  • 黑窗口不要关
  • 完成后浏览器会打开；也可手动访问 http://localhost:3000

如果没有 Node，也可先双击 安装依赖.bat，完成后再双击 一键启动.bat。

打开网页后怎么用

1进入设置

  1. 看网页右上角，点齿轮图标
  2. 按向导或「API 配置」填写阿里云百炼等 API Key
  3. 点保存

没有 API Key 时，部分功能会用演示/降级结果，效果较差。

2四个主要功能

  • 脚本工作台：生成口播/拍摄脚本（不依赖样例 Excel）
  • 发布前审片：上传视频做审片（需要本机 FFmpeg）
  • 数据匹配：把工作簿和本地视频关联（需要你自己的数据文件）
  • 数据分析：看分析结果

关于红色 ENOENT / 找不到 xlsx

如果提示找不到工作簿：

  • 脚本工作台不依赖 Excel，可以直接生成脚本
  • 请确认当前使用的是「脚本工作台」，而非需要工作簿的数据分析功能
  • 「数据匹配」若要用真实表格，需自行准备 Excel/视频再配置路径

常见问题

Q1：黄框只有「完成 / 移到废纸篓」

这是普通双击被系统拦截。请改用本文 Mac 第 2～4 步（终端 + bash + 拖文件），不要双击 .command。

Q2：Permission denied / 没有访问权限

  1. 确认文件已复制到桌面（路径里不要有 WeChat / xinWeChat）
  2. 确认终端里先输入了 bash （带空格）再拖文件
  3. 不要只拖文件、没有 bash

Q3：终端里一堆 npm warn

警告可以忽略。只要最后能打开网页就行。

Q4：网页打不开

  1. 看启动窗口是否还在跑、有没有红色 Error
  2. 手动访问 http://localhost:3000
  3. 等首次安装完成后再刷新
  4. 确认没有别的程序占用 3000 端口

Q5：点「生成脚本」报找不到 Excel

脚本生成不依赖 Excel。请确认进入「脚本工作台」；若仍报错，请记录错误信息并通过 GitHub Issues 反馈。

Q6：Windows 提示找不到 winget / 装不上 Node

  1. 先双击 安装依赖.bat
  2. 或手动安装 Node LTS：https://nodejs.org/
  3. 安装完成后重新开一个黑窗口，再双击一键启动

Q7：自动安装失败 / Homebrew / git fetch 报错

启动脚本不自动安装 Homebrew。请先手动安装 Node，再启动应用。

  1. 用 Safari 打开 nodejs.org，装绿色 macOS 安装程序
  2. 关掉旧终端，新开终端，执行 node -v 确认成功
  3. 再用 bash + 拖文件启动
