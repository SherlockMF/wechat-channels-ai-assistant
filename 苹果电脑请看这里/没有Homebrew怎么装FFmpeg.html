没有 Homebrew 怎么装 FFmpeg（Mac）

推荐用「方法一」：不用装 Homebrew，直接下载两个文件。
Homebrew 在国内经常因网络失败，可以不装。

1方法一：直接下载（推荐，不用 Homebrew）

  1. 用 Safari 打开：https://evermeet.cx/ffmpeg/
  2. 下载 ffmpeg（页面上的下载链接 / ZIP）
  3. 同一页再下载 ffprobe
  4. 在「下载」文件夹里解压，得到两个没有后缀的文件：
    • ffmpeg
    • ffprobe
  5. 打开终端（Command + 空格 → 输入「终端」）
  6. 把下面整段复制粘贴到终端，回车：
sudo mkdir -p /usr/local/bin sudo mv ~/Downloads/ffmpeg /usr/local/bin/ffmpeg sudo mv ~/Downloads/ffprobe /usr/local/bin/ffprobe sudo chmod +x /usr/local/bin/ffmpeg /usr/local/bin/ffprobe ffmpeg -version ffprobe -version
  1. 出现 Password: 时，输入 Mac 登录密码（屏幕不会显示），输完回车
  2. 若提示找不到 Downloads 里的文件：用访达打开「下载」，确认解压后的文件名就是 ffmpeg / ffprobe，再改路径或把文件拖到终端替换命令里的路径
  3. 最后两行能刷出版本信息 = 成功
  4. 重新启动本软件，设置里点「重新检测」，FFmpeg / FFprobe 应变绿

2方法二：先装 Homebrew，再装 FFmpeg

仅在网络较好时尝试（连 GitHub 容易失败）。

  1. 打开终端，粘贴下面整行后回车：
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  1. 按提示按回车；遇到 Password 输入登录密码（不显示），回车
  2. 若多次 Failed / git fetch 失败：放弃方法二，改用上面的方法一
  3. 安装成功后（Apple 芯片 Mac）再执行：
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)" brew install ffmpeg
  1. 新开终端检查：
ffmpeg -version ffprobe -version

装好后怎么确认软件里也绿了

  1. 关掉正在跑的启动窗口
  2. 重新用 bash 拖文件启动（或双击桌面「视频号助手」）
  3. 打开设置 → 重新检测
  4. FFmpeg、FFprobe 都显示「就绪」即可

两个都会一起好，一般不用分别装。
