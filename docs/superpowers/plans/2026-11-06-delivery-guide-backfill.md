# 口播演讲提示补齐

用户已要求全部补齐旧稿兼容及已有口播稿的演讲提示入口。

设计：读取稿件时按当前正文派生演讲提示，复用已有对齐校验与规则生成器；已有且对齐的模型攻略保持不变。基础提示明确标为本地规则，不调用受权限限制的模型，不重写原稿或批量迁移用户数据。手改后支持按当前正文更新，返回晚到的结果不能绑定到新正文。所有旧稿及优化前版本均覆盖。
