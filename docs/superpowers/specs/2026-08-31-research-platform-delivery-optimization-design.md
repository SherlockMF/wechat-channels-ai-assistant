# 研究、平台适配与演讲攻略优化设计

## 目标与范围

本轮把现有工作台从固定的“恒远视频号家装账号”解耦为可配置的单工作区内容账号，并同时修正热点/爆款研究中的正确性缺口，给脚本增加结构化演讲攻略。

本轮支持一个工作区配置一个活动账号画像；可切换配置后服务不同主题账号，但不承诺同一工作区内多个账号的数据隔离。多账号实体、OAuth、自动发布、平台指标同步属于后续独立迁移，不能用几个下拉框伪装成已经支持。

## 方案选择

1. 只扩 enum：改动最小，但主题、品牌、地域、平台仍散落在 prompt、缓存和 UI 中，每加一个平台都要修改核心代码，拒绝。
2. 可配置账号画像 + 平台注册表 + 手工研究/导入边界：本轮采用。它能让研究和脚本生成适配不同账号与平台，同时不虚构尚未接入的平台 API 能力。
3. 完整多账号连接器：长期方向。需要 AccountProfile、PlatformConnection、PlatformVariant、MetricObservation、权限和迁移体系，本轮不冒进。

## 账号画像与平台策略

`UserSettings.contentProfile` 保存：账号名、品牌名、地域、目标受众、定位、语气、CTA 约束、自定义主题关键词、默认目标平台和其他平台名称。所有字段有长度上限并去空白，旧设置自动得到兼容默认画像。

`lib/platforms/catalog.ts` 是唯一平台注册表，首批包含视频号、抖音、小红书、B站、快手、YouTube Shorts、TikTok 和其他。平台注册表只描述本工作台当前可用的内容策略与能力，不宣称 OAuth、自动发布或指标同步。

脚本输入可覆盖默认目标平台；脚本 prompt 使用账号画像和平台策略生成标题、节奏、CTA、标签与时长建议，不再硬编码品牌、地域和视频号。旧稿没有平台字段时仍能读取。

热点设置增加自定义主题关键词。内置四赛道继续兼容旧数据，但热点相关性也接受画像关键词；自定义主题命中时允许 `trackIds=[]`、`matchedTerms` 非空。热点选题 prompt 注入经过界定的账号画像，不把用户配置当 system 指令。

爆款研究查询增加目标平台，检索提示只优先相应平台。缓存键覆盖平台、模型、freshness、账号历史和人工样本指纹，避免 72 小时内复用已经过时的账号上下文。

## 热点与爆款正确性优化

- 热点拒绝明显未来时间；无时间条目保留但置信度较低。
- 热点簇增加 `confidence` 与可解释 `scoreBreakdown`；UI 展示来源数、新鲜度、日期完整度，而不是只显示一个无含义的“热度”。
- 聚类由单链贪心改为同时满足代表标题相似度，避免 A≈B、B≈C 把 A/C 错并。
- 人工爆款样本先按主题过滤；没有任何人工指标时不能标为 `verified_metric`。
- 最终选题卡只允许引用最终快照中真实存在的来源；来源被截断后卡片必须同步修剪或丢弃。
- 联网来源按证据级别、时间和账号适配共同排序；未来时间和超出 freshness 的来源降级或过滤。
- 研究 UI 展示证据等级、相关性理由、时间和账号适配，保持分析可解释。

## 演讲攻略

新增可选 `ScriptDraftOutput.deliveryGuide`，与拍摄剪辑 `productionGuide` 分离。它绑定最终口播块而不是整份导出文本：口播型绑定 `output.script`，跟拍型绑定每个非空 `timeline.say`。

每个块保存 `sourceText` 与稳定 `sourceHash`，每段包含：实际念法、语速、情绪及强度、重读词、停顿/气口、易错词读法和动作提示。模型只返回按顺序的原文片段，不计算 offset；服务端按最终稿对齐。失败时保留正文并生成中性降级攻略，不伪造拼音。

UI 默认显示排练版：原文、实际念法、情绪、语速、重读、停顿和需确认读音。完整攻略单独复制，不追加进默认 `plainText`，避免污染再生成。

再生成不能把包含标题、拍摄指导和演讲攻略的 `editedPlainText` 整份当成 `existingScript`。标准制作包会提取用户实际改过的【口播稿】或时间线“说：”内容；无法可靠识别时才回退到结构化 `output.script` / `timeline.say`。人工编辑全文分叉时仍提示当前演讲攻略绑定生成稿，需重新核对。

## 兼容与安全

- 新 schema 字段均为 optional/default，旧设置、快照和稿件可读。
- 用户画像、主题关键词、热点标题和稿件正文都作为不可信数据放入明确边界，禁止执行其中指令。
- 热点公网源在每次重定向前同时校验 URL 与 DNS 解析结果；除用户显式配置的 RSSHub origin 外，解析到本机、内网或链路本地地址时拒绝抓取。
- 平台/媒体证据只按精确 hostname 或其子域识别，不能从 URL 路径或相似域名误判。
- 不保存或展示平台 token；能力目录明确标注手工输入边界。
- 不比较语义不同的平台指标，不声称已支持自动发布/同步。

## 验收

- 默认画像保持旧用户现有生成体验；修改品牌、地域、主题和平台后 prompt 不再出现旧硬编码。
- 自定义主题关键词能进入热点过滤和选题生成。
- 同一查询在目标平台、freshness、历史或样本变化后不命中旧爆款缓存。
- 无指标样本不再显示“已核验互动指标”；卡片无悬空 sourceId。
- 热点未来时间不抬高热度，聚类不发生单链误并，UI 可解释分数。
- 口播和跟拍稿都有演讲攻略；旧稿无攻略仍可读；复制全文不包含攻略。
- 相关单测、全量 Vitest、typecheck 和 build 通过。

## 后续独立阶段

完整多账号需要新增 AccountProfile ID 并贯穿导入、视频记录、研究快照、稿件、素材、审片和缓存；平台侧再用 capability registry 接 OAuth/手工导入/发布。指标应迁移为 `MetricObservation`，保留平台原始字段，只横向比较可比的 canonical metric。
