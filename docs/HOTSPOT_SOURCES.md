# 微信视频号 AI 创作助手 · 热点数据源

[返回项目说明](../README.md)

热点研究直接获取公开榜单和订阅内容，结合账号赛道与自定义主题词过滤、聚类，再生成选题建议。默认无需 RSSHub、Redis、浏览器容器或 Docker。

## 默认九个来源

| 来源 | 抓取方式 |
| --- | --- |
| 微博热搜 | 平台热搜 JSON 接口 |
| 百度热搜 | 热榜网页内嵌数据 |
| 抖音热榜 | 平台榜单 JSON 接口 |
| 今日头条 | 热榜 JSON 接口 |
| 36氪热榜 | 平台榜单 POST 接口（不同于原来的36氪快讯） |
| B站排行 | 平台排行 JSON 接口 |
| IT之家、极客公园、少数派 | 站点 RSS |

平台接口并非稳定开放 API，改版或限流时仍可能失效。每个来源独立显示成功、条数或失败原因；不会因为一个源失败而阻断其他源。

## 旧配置

精确匹配旧内置配置的36氪、微博、抖音会升级为直连并保留启停状态。旧内置知乎热榜停用，当前没有经过验证的知乎直连适配。用户自定义 RSS、Atom、JSON Feed 和 RSSHub 来源不会被删除；只有存在旧 RSSHub 来源时，设置中才显示折叠的兼容配置。

想使用全部新来源，在设置点击“恢复默认源”。历史快照继续保留，但旧抓取策略的缓存不会用于新请求。

## 筛选与使用

1. 提取标题、链接及来源实际提供的发布时间、摘要；热榜无发布时间时不补造日期。
2. 按账号赛道、主题词和时效筛选，合并相近事件。
3. 生成选题卡并引用实际来源；模型不可用时仍展示热点和源状态。
4. 选题可直接用于脚本，或点击“收藏到选题池”，稍后在“创作资料”排期。

平台排行顺序只用于该来源选取条目；当前聚类热度是跨来源与时效的综合评分，不等同于平台热度值。选题建议不代表已核实事实，也不保证播放表现。

## 刷新与验证

榜单刷新间隔为 20 分钟；已生成的快照保留原有 8 小时创作引用有效期，避免编辑过程中突然丢失热点上下文。页面打开时若已到刷新时间会刷新一次，手动强刷可绕过缓存；所有来源失败时展示旧快照并标记过期。

在 `apps/web` 运行 `node scripts/live-hotspot-fetch-test.mjs` 可无缓存验证九个默认来源，不调用模型、不写用户数据。必须全部来源成功且非空才返回成功退出码。

## 请求边界

- 默认只请求 HTTPS 公网地址，拒绝 IP 字面量、内网 DNS 与不安全重定向；旧用户自建 RSSHub 仅在显式配置 origin 时例外。
- 平台适配器只接受固定接口地址；未知地址不会带平台请求参数发出请求。
- 单源超时 8 秒、响应上限 2 MB、并发上限 4，整次预算 20 秒。
- 标题和摘要是资料，不执行其中的指令；网络失败只补充错误码，不输出凭证或完整底层错误对象。
