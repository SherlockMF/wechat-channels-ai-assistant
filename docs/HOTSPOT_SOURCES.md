# 微信视频号 AI 创作助手 · 热点数据源

[返回项目说明](../README.md)

热点研究从公开来源获取近期内容，结合账号赛道与自定义主题关键词过滤、聚类，再生成选题建议。内置方向覆盖智能家居、全屋智能、净水、装修水电与家电新品。

## 来源类型

| 来源 | 内容 | 使用条件 |
| --- | --- | --- |
| RSS / Atom / JSON Feed | 媒体和站点的订阅条目 | 可访问的订阅地址 |
| RSSHub | 站点内容与热搜榜 | 可用的 RSSHub 地址与路由 |
| DashScope 联网检索 | 相关网页与补充信息 | 可用的 Provider 与 API Key |

各来源独立处理。RSSHub 不可用时，对应来源会跳过；Provider 不可用时，联网补充会显示失败。单源失败不会中断整次抓取，页面展示每个源的状态和原因。

## 筛选与选题

1. 提取标题、链接、发布时间与摘要。
2. 按时间范围、账号赛道与自定义主题关键词筛选相关条目。
3. 合并相近内容，形成热点聚类。
4. 结合创作方向生成选题建议，并保留来源信息供核对。

综合热榜覆盖范围较广，未必与账号方向相关。联网检索结果也不代表已经验证的播放量或爆款表现，需要回到原始来源确认。

## 刷新与异常

默认支持手动刷新，页面打开时若快照过期会自动刷新一次。来源改版、限流、网络异常或订阅关闭都可能导致抓取失败。

在热点页面查看来源状态，在设置中停用不可用来源或调整地址。避免频繁刷新，以减少重复抓取和限流。

## 数据约束

- 除显式配置的 RSSHub 地址外，来源使用 HTTPS，并限制 IP 字面量和内网地址。
- 单源超时 8 秒、响应上限 2 MB、并发上限 4，整次抓取预算 20 秒。
- 标题与摘要作为不可信数据处理，不执行其中的指令。
- 选题建议保留证据限制，不将检索摘要当作已确认事实。
