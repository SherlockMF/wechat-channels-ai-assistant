# 微信视频号 AI 创作助手 · 功能使用说明

[返回项目说明](README.md)

首次使用先看 [安装与启动](README.md#快速启动本地使用)。默认在仓库根目录执行 `npm ci`、准备 `.env`，再运行 `npm run dev`；访问终端显示的本地地址。

## 脚本工作台

入口：`/scripts`。

1. 创建脚本，选择内容形态、业务主题与「已拍摄 / 未拍摄」。
2. 已拍摄内容生成素材描述与剪辑建议；未拍摄内容生成拍摄分镜与剪辑建议。
3. 查看结构化预览及全文，编辑后自动保存；保存状态和失败重试显示在工具栏。
4. 在全文中选中文字，选择局部改写操作；先预览，确认后替换。生成建议期间正文改变时，旧建议不能覆盖新内容。
5. 点击「口播语气／演讲提示」查看逐句语气、强度、语速、重读、停顿、换气和动作；所有旧稿打开时自动补齐，原稿正文不变。本地规则生成的基础提示会明确标注来源，已有对齐的模型攻略保持不变。
6. 改稿后点击「按当前口播更新提示」，再进入「提词排练」；勾选「语气与排练提示」即可边读边看。支持字号、速度、镜像和暂停；过期提示不会套用到新正文。基础提示不调用模型，无需模型权限。
7. 需要另一种表达时使用再生成，原记录会保留。

全文末尾包含「拍摄与剪辑指导」。手动修改全文后，结构化预览可能不同步，复制时以全文为准。未配置 AI 或 Provider 返回无效结果时，详情会明确标注 mock 或降级状态。

## 创作资料

- **选题池**：手动记录或从热点卡收藏，设置日期与待写/已排期/已成稿状态。「写这条」只预填脚本，不自动生成。
- **真实素材**：保存经历、数据、案例、金句、观察及标签，生成时按主题选取最多六条相关记录。语气样本不充当新稿的事实依据。
- **内容栏目**：设置栏目用途、写作规则和每篇需要的素材字段；新建脚本时选择栏目并填写必填资料。
- **语气样本**：加入本人确认过的稿件，再点击「重新学习语气」。增删样本会使旧档案失效；模型失败保留样本并显示错误，不用演示结果冒充已学习。
- **生成依据**：脚本保存当时的账号定位、语气档案、选用素材和栏目输入。修改资料不影响旧稿；旧稿「再生成」沿用已有快照，新建稿使用最新资料。
- **存储**：本地按账号独立保存，Sites 版本使用 D1。资料不存在时可以新建；文件或数据库记录损坏时会报错，不覆盖为一个空库。

## 发布前审片

入口：`/review`。

1. 上传待发布视频，填写标题、标签和创作目标。
2. 查看审片报告中的证据、问题和修改建议。
3. 上传修改后的视频版本，对比已改善、仍存在与新增的问题。
4. 结合封面建议调整表达，保留需要的报告内容。

媒体处理依赖 FFmpeg / ffprobe；真实转写与视觉分析取决于相应 Provider 的可用性。缺少证据的结论应作为待验证建议。

## 数据导入与匹配

导入入口：`/imports/new`；已有数据可从「数据匹配」进入。

1. 准备包含「视频号数据明细」工作表的 Excel 工作簿与对应视频素材。
2. 导入后检查字段预览、数据校验结果及错误行号。
3. 系统按平台视频 ID、标题和文本相似度生成匹配候选。
4. 人工确认不确定的对应关系，再进行分析；导入有误时可回滚该批次。

支持 MP4、MOV、WebM 视频。工作簿中的日期、百分比、带分隔符数字和空值会被标准化；同一批次的视频 ID 会进行去重校验。

## 数据分析与报告

入口：`/analysis`。

1. 按发布时间选择最近 5 / 10 / 20 条、全部视频或手动勾选。
2. 查看账号整体、近期基线与互动率等指标。
3. 阅读报告中的数据事实、合理推断和执行动作。
4. 编辑并保存报告，按需要复制或导出 Markdown。

本地规则诊断基于数据指标，不代表已经理解视频画面。样本量不足、缺少媒体证据或缺少逐秒留存时，应结合报告中的限制判断结论。

## 热点与爆款研究

入口：`/hotspots`。

1. 查看近期热点，结合账号赛道与自定义主题词筛选方向。
2. 阅读来源、时间、摘要和选题建议，回到原文核对重要信息。
3. 结合参考内容形成自己的创作主题，再进入脚本工作台。
4. 需要更新内容时手动刷新，并查看各数据源的状态。

单一数据源失败不会中断整次抓取。联网检索得到的网页不等同于已验证的播放量或爆款数据。来源机制见[热点数据源](docs/HOTSPOT_SOURCES.md)。

## 功能设置

入口：`/settings`。

- 配置 AI Provider、模型及 API Key。
- 调整研究数据源、账号方向与主题关键词。默认九个来源直接抓取，不需要 RSSHub；仅已有自定义 RSSHub 来源保留兼容设置。
- 根据页面显示的 Provider 状态区分真实 AI 输出、规则诊断与模板结果。

业务数据和密钥仅用于自己的工作环境；反馈问题时，请移除截图与日志中的密钥和个人数据。
