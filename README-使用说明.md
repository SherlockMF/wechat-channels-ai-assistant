二、苹果电脑（Mac）第一次启动（请严格按顺序）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【不要做】
× 不要普通双击「请右键点我启动.command」（会被系统拦住）
× 不要在微信文件夹里运行
× 不要依赖自动安装 Homebrew（网络常失败）

【请先做一次】安装 Node
  1) Safari 打开 https://nodejs.org
  2) 点绿色「macOS 安装程序(.pkg)」装完
  3) 关掉所有旧终端，重新开一个新终端
  4) 输入 node -v 和 npm -v，应显示版本号

【然后启动】

第 1 步：打开桌面 →「视频号内容诊断助手」→「苹果电脑请看这里」

第 2 步：打开「终端」
  1) 按键盘：Command（⌘）+ 空格
  2) 输入：终端
  3) 回车

第 3 步：在终端输入下面 4 个字符（最后是空格），先别回车：

     bash 

  注意：bash 是英文；后面一定有空格；光标停在空格后。

第 4 步：把启动文件拖进终端
  1) 打开：桌面 → 视频号内容诊断助手 → 苹果电脑请看这里
  2) 找到：请右键点我启动.command
  3) 按住它，拖到终端窗口里松开
  4) 终端会出现很长一串路径（正常）
  5) 按回车

第 5 步：等待（首次装项目依赖可能要几分钟）
  · 很多 npm warn → 可忽略
  · 黑窗口不要关
  · 浏览器打开 http://localhost:3000
  · 没有 FFmpeg 也能先用脚本工作台

第 6 步（推荐，方便下次）：
  成功后桌面可能出现「视频号助手」
  若没有，可再开一个终端窗口，整段粘贴下面内容后回车：

ROOT="$(ls -d ~/Desktop/视频号内容诊断助手* 2>/dev/null | head -n 1)" && cat > ~/Desktop/视频号助手.command <<EOF
#!/bin/bash
cd "$ROOT" || exit 1
[ -x /opt/homebrew/bin/brew ] && eval "\$(/opt/homebrew/bin/brew shellenv)"
echo "正在启动…请不要关闭本窗口"
(sleep 5; open "http://localhost:3000") &
npm run dev
EOF
chmod +x ~/Desktop/视频号助手.command && echo "已创建：桌面上的「视频号助手」"


【Mac 下次启动】
  · 有「视频号助手」→ 直接双击它
  · 没有 → 重复上面第 2～5 步（会快很多，不必再装依赖）

三、Windows 第一次启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第 1 步：确认文件夹在桌面

第 2 步：打开文件夹，双击「一键启动.bat」

第 3 步：若提示「Windows 已保护你的电脑」
  → 点「更多信息」→「仍要运行」
  若弹出权限，选「是」

第 4 步：等待黑窗口（不要关）
  首次会装 Node / FFmpeg / 项目依赖，以及热点热榜需要的 Docker Desktop，需联网
  · 弹出 Windows 权限窗口时点「是」
  · Docker Desktop 首次打开时接受许可条款
  · 若提示必须重启：重启电脑后再次双击「一键启动.bat」
  · RSSHub 首次会下载容器镜像，以后不会重复安装
  完成后浏览器会自动打开实际地址（默认从 http://localhost:3000 开始选空闲端口）

备选：可先双击「安装依赖.bat」，完成后再「一键启动.bat」
RSSHub 单独安装/修复：双击「安装RSSHub.bat」


【Windows 下次启动】
  双击「一键启动.bat」即可；脚本会自动启动 Docker 与 RSSHub，不会重复安装

六、常见问题（务必先看）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q：黄框只有「完成 / 移到废纸篓」
A：不要双击 .command。改用「终端 + bash + 空格 + 拖文件」。

Q：Permission denied / 没有访问权限
A：1) 必须用桌面上的副本（路径不要含 WeChat）
   2) 必须先输入 bash+空格，再拖文件
   3) 不要只拖文件没有 bash

Q：自动安装失败 / Homebrew / git fetch 失败
A：正常。请手动装 Node（nodejs.org 绿色按钮），新开终端后再 bash 启动。
   新版不再自动装 Homebrew。

Q：一堆 npm warn
A：可忽略。能打开网页就行。

Q：生成脚本报找不到 xlsx
A：请用最新交付包并重新启动。脚本生成不依赖那份样例 Excel。

Q：网页打不开
A：确认黑窗口还在；查看黑窗口显示的实际网址；等首次安装结束。

Q：Docker / RSSHub 要额外收费吗
A：RSSHub 是开源软件。Docker Desktop 对个人、教育、非商业开源项目，以及少于 250 人且年营收低于 1000 万美元的小企业免费；大型企业和政府机构需按 Docker 许可购买订阅。

Q：Docker 显示 Virtualization support not detected
A：本机首次自动启用 WSL 2 后必须重启 Windows。先重启，再双击「一键启动.bat」；若重启后仍出现此提示，再检查 BIOS 虚拟化设置。

Q：RSSHub 没启动成功，工作台还能用吗
A：能。普通 RSS 热点源仍可用；36氪、微博、知乎、抖音等依赖 RSSHub 的来源会暂时跳过。处理提示后重新双击「一键启动.bat」即可自动重试。

八、研究热点与 RSSHub（可选）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

「研究热点」从新闻 RSS 与热搜榜抓取近期条目，按赛道过滤后给出选题。
顶栏进入「研究热点」即可使用；默认手动刷新，打开页面时若快照过期会自动刷新一次。

【官方 RSS】
  不需要额外部署，在「设置 → API 配置 → 研究热点」保持启用即可。

【热搜榜（微博/知乎/抖音等）】
  需要自建 RSSHub（需安装 Docker）：
  1) 在项目根目录打开终端，执行：
     docker compose -f docker-compose.rsshub.yml up -d
  2) 浏览器访问 http://127.0.0.1:1200/healthz 确认正常
  3) 设置页「研究热点」里 RSSHub 地址填：http://127.0.0.1:1200
  4) 回到「研究热点」页点「手动刷新」

  停止 RSSHub：docker compose -f docker-compose.rsshub.yml down

【定时刷新（可选）】
  若希望每天固定时间预抓取热点（Web 需已启动）：
  1) 在 Web 进程环境变量里设置 HOTSPOT_REFRESH_TOKEN=一串随机密钥
  2) 用 Windows「任务计划程序」每天运行：
     scripts\schedule-hotspot-refresh.ps1
     （运行前同样设置 HOTSPOT_REFRESH_TOKEN 环境变量）
  未配置 token 时，带 Bearer 的刷新请求会被拒绝；平时手动刷新不受影响。

  更详细的源说明见项目内 docs/HOTSPOT_SOURCES.md
